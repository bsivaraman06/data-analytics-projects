HR Analytics Dashboard using Power BI

Project Overview

Developed an interactive HR Analytics Dashboard using Microsoft Power BI to analyze employee distribution, attrition trends, department performance, salary slabs, age groups, and work experience.

Problem Statement

Understanding employee attrition and workforce distribution across departments, age groups, and salary levels can be challenging when analyzing raw HR data.

Solution

Created an interactive Power BI dashboard with KPI cards, charts, and slicers to explore employee demographics and attrition patterns.

Dataset

- HR Analytics Dataset
- Employee information and attrition details
- Department, job role, salary, age, gender, and experience fields

Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

Key Performance Indicators

- Total Employees: 1,417
- Active Employees: 1,186
- Attrition Count: 231
- Attrition Rate: 16.30%
- Average Age: 36.94
- Average Experience: 7.04 years

Dashboard Visualizations

- Attrition by Department
- Attrition by Salary Slab
- Attrition by Job Role and Job Satisfaction
- Age Group Distribution
- Attrition by Gender
- Attrition Trend by Experience
- Department-wise Employee Count

Interactive Features

- Age Group Slicer
- Department Filter
- Interactive Dashboard Visuals

Key Insights

- The dashboard recorded 231 employee attritions.
- The overall attrition rate was 16.30%.
- Operations had the highest department-wise employee count.
- The 26–35 age group had the largest employee representation.

Conclusion

This project provided practical experience in HR data analysis, KPI development, dashboard creation, and identifying employee attrition patterns using Power BI.
