Excel Sales Dashboard

Project Overview

Developed an interactive Sales Dashboard using Microsoft Excel to analyze sales performance, regional contributions, product sales, and salesperson performance.

Problem Statement

Analyzing sales data manually makes it difficult to identify top-performing regions, products, and salespersons.

Solution

Used Excel formulas, Pivot Tables, and charts to organize sales data and create a dashboard for better business insights.

Dataset Details

- 100 sales records
- 5 regions
- 10 products
- 10 salespersons

Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts and Dashboard Visualization

Key Analysis

- Region-wise Total Sales
- Salesperson-wise Performance
- Product-wise Units Sold
- Overall Sales and Profit Analysis

Key Insights

- Total Sales: 13,489,000
- Total Units Sold: 1,062
- Total Profit: 4,445,200
- Central region recorded the highest sales among the five regions.

Conclusion

This project helped develop practical skills in Excel data analysis, Pivot Table reporting, formula calculations, and dashboard creation.
