Weather Data Analysis Using Python

Project Overview

Analyzed historical weather data containing 96,453 records and 12 columns to understand weather conditions, temperature variations, humidity levels, wind speed, and precipitation patterns.

Problem Statement

Analyzing large weather datasets manually makes it difficult to identify weather patterns, understand temperature variations, and compare different weather conditions.

Solution

Used Python libraries to clean, filter, analyze, and visualize weather data. Applied statistical techniques and exploratory data analysis to identify patterns and generate meaningful insights.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Data Cleaning

- Identified and removed 24 duplicate records.
- Identified 517 missing values in the Precip Type column.
- Checked dataset structure and data types.

Analysis Performed

- Temperature and humidity filtering.
- Weather condition analysis using GroupBy.
- Precipitation type analysis using Value Counts.
- Statistical analysis of temperature.
- Wind speed analysis by precipitation type.

Data Visualizations

- Temperature Distribution – Histogram
- Temperature Boxplot
- Precipitation Countplot
- Temperature vs Apparent Temperature – Scatterplot
- Temperature by Precipitation Type – Violinplot
- Humidity Distribution – KDE Plot
- Weather Correlation – Heatmap
- Precipitation Distribution – Pie Chart

Key Insights

- Partly Cloudy was the most frequently recorded weather condition.
- Rain was the most common precipitation type.
- Weather conditions showed variations in average temperature and humidity.

Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, statistical analysis, and data visualization to understand historical weather patterns.
