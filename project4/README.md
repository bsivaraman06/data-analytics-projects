Fashion Trends Analytics using Python & SQL

Project Overview

Developed a Fashion Trends Analytics project by connecting Python with a MySQL database to analyze product details, sales performance, customer ratings, and payment methods.

Problem Statement

Analyzing fashion product and sales data separately makes it difficult to understand product categories, monthly sales trends, pricing patterns, and customer preferences.

Solution

Connected Python to MySQL and executed SQL queries to retrieve, analyze, and visualize data from the Products and Sales tables. Created charts and dashboards to present meaningful insights.
